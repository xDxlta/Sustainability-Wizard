Sources and assumptions

Every number the wizard uses is listed here with its provenance. Sourced means a published value whose page was opened and whose quoted wording is on it; Sourced, unverified means the page could not be opened when this version was built, so the value and the quote come from a search-engine excerpt and must be checked (see VERIFY.md); Derived values are arithmetic on other values; Assumption values have no published source and can be changed on the result page.

Where sources disagree, one value per factor is chosen by a rule stated once: see "Choice rules" below.
